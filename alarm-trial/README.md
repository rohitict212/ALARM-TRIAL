# Basic Alarm App

A small trial alarm app built with plain HTML, CSS, and JavaScript.

## Features

- Shows current time
- Lets the user set an alarm time
- Plays a simple tone when the time matches
- Clear button to remove the alarm

## Run it locally

Open `index.html` in a browser, or serve the folder with a local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
